# Connected Traversability Places Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stop traversability places (`MESH_PLACES`) from being created behind walls with no physical connection, so the place graph is safe for planning.

**Architecture:** Two parts. (A) Reduce phantom free-space at the source via config (`sensor.max_range` 10→5 m, tighten the adaptive interpolator). (B) Make the traversability clustering's robot-seeded flood fill enforce genuine physical connectivity: 4-connectivity (no diagonal wall-gap leaks) plus a minimum-passage-width guard (a "grow-through-core" BFS that won't propagate across gaps thinner than N voxels).

**Tech Stack:** C++17 (hydra, config_utilities, spark_dsg, Eigen, GoogleTest), colcon/CMake build, YAML config generated by `dcist_launch_system/config_generation/generate_configs.py`.

## Global Constraints

- All new `RegionGrowingTraversabilityClustering::Config` knobs MUST default to current upstream behavior: `use_diagonal_connectivity = true` (8-connected) and `min_connection_width_voxels = 1` (off). Only the dcist config opts in.
- Voxel size is **0.1 m** (so `min_connection_width_voxels: 2` ≈ 20 cm).
- `dcist_launch_system/config/` is a **generated** artifact. Edit only `config_generation/base_params/hydra.yaml`, then regenerate with `scripts/generate_configs.sh`. Never hand-edit `config/`.
- Branches already created: `feature/connected-trav-places` in **hydra** (off `feature/image_storage` @ eab81ca3) and in the **superproject** (off `feature/openset_planning` @ 9f1ded7).
- Push to **harelb** forks only, never origin/MIT-SPARK. No upstream PR unless asked.
- `neighbors_` (in `region_growing_traversability_clustering.h`) is ordered: indices 0–3 are the 4 orthogonal offsets (bottom/left/top/right), indices 4–7 are diagonals. 4-connectivity = use the first 4.

```cpp
VoxelSet RegionGrowingTraversabilityClustering::erodeCandidates(
    const VoxelSet& candidates, int radius) {
  if (radius <= 0) {
    return candidates;
  }
  VoxelSet eroded;
  for (const auto& v : candidates) {
    bool keep = true;
    for (int dx = -radius; dx <= radius && keep; ++dx) {
      for (int dy = -radius; dy <= radius; ++dy) {
        if (std::abs(dx) + std::abs(dy) > radius || (dx == 0 && dy == 0)) {
          continue;  // 4-connected (plus) ball, excluding the center
        }
        if (candidates.find(v + VoxelIndex(dx, dy, 0)) == candidates.end()) {
          keep = false;
          break;
        }
      }
    }
    if (keep) {
      eroded.insert(v);
    }
  }
  return eroded;
}

VoxelSet RegionGrowingTraversabilityClustering::growConnectedWithMinWidth(
    const VoxelSet& candidates,
    const VoxelSet& core,
    const VoxelIndex& seed,
    size_t num_neighbors) {
  VoxelSet result;
  if (candidates.find(seed) == candidates.end()) {
    return result;
  }
  VoxelSet visited;
  std::queue<VoxelIndex> queue;
  queue.push(seed);
  visited.insert(seed);
  while (!queue.empty()) {
    const auto current = queue.front();
    queue.pop();
    result.insert(current);
    if (core.find(current) == core.end()) {
      continue;  // narrow voxel: include but do not propagate through it
    }
    for (size_t k = 0; k < num_neighbors && k < neighbors_.size(); ++k) {
      const VoxelIndex n = current + neighbors_[k];
      if (candidates.find(n) != candidates.end() && visited.insert(n).second) {
        queue.push(n);
      }
    }
  }
  return result;
}
```

## Notes / known limitations (from the spec)

- **Glass / never-meshed walls:** if a wall produces no depth return, the free-space is
  continuous with no INTRAVERSABLE gap, so Part B cannot separate it; only Part A's
  range cap helps. Calibrate expectations for building-45 if glass partitions dominate.
- Region archival lifecycle / `pruneRegions` and the classification-time gate are
  intentionally untouched (see spec).
