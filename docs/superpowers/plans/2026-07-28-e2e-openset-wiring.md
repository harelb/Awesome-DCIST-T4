# E2E Open-Set Wiring (NL + Query-Time Re-Query) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One command (`explore_mission.py --nl "find the suitcase and bring it to the lobby"`) runs NL → typed missing-symbol → explore → SAM3 query-time re-query over accumulated keyframes → labelspace-append + inject → plan → deliver, on floor3 with realistic gate assets; honest exit 4 when the class is absent.

**Architecture:** Harness-orchestrated (Approach A of the spec). The LLM is called in-process via `nl_grounding_check.request_llm_goal`; the novel-object convention `o_<class>` flows through shipped omniplanner grounding untouched (NO omniplanner changes). SAM3 runs as a warm HTTP server in its own venv (numpy isolation is process-level); JSON detections cross the boundary; injection happens on the saved graph via a new `_l2p0` append helper + the existing `ensure_object_of_class`.

**Tech Stack:** dcist_sim (python, spark_env pytest), nlu_interface (prompt yaml + OpenAI client), agentic_navigation sam3_frontend (read-mostly; runs in `~/environments/dcist/sam3` venv), Isaac Sim 6.0 GPU gates.
