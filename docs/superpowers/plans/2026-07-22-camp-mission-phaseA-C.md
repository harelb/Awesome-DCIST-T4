# Camp Mission Sim (Phases A–C) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Single Spot executes "block the intersection with a cone" end-to-end in a new compact outdoor camp Isaac environment: live map → Neo4j ingest with an injected `intersection` Room → `mission_cli` goal → omniplanner → executor, producing an `adt4_output` scene-graph folder + third-person video.

**Architecture:** New `camp_a` env USD + `camp_smoke.yaml` scenario (kinematic) feed the existing mapping/e2e machinery. Regions are declared in scenario YAML, injected into the saved DSG as ROOMS-layer nodes by a new `region_injector` immediately before heracles ingest (so they land in Neo4j through the canonical `spark_dsg_to_db` path), and served to omniplanner via `heracles_publisher` on a dedicated topic. A new `mission_cli` resolves the block-verb against Neo4j and publishes the fast rearrangement-domain PDDL goal.

**Tech Stack:** Isaac Sim 6.0.1 venv (`~/environments/dcist/isaac_sim`), ROS2 Jazzy, spark_dsg python, heracles/Neo4j (creds `HERACLES_NEO4J_*` in ~/.zshrc), omniplanner, config_utilities config generation.

**Spec:** `docs/superpowers/specs/2026-07-22-camp-mission-sim-design.md`. Two approved implementation deltas vs spec text: (1) camp lighting is authored inside `camp_a.usd` (field_a.usd precedent: DomeLight+DistantLight embedded in env USD — NO stage.py change); (2) region injection happens by augmenting the loaded spark_dsg right before `load_dsg_to_db` (which wipes the DB), not by post-ingest Cypher — same Neo4j outcome via the schema-correct path.

### Task B3: region_injector library

**Files:**

**Interfaces:**
- Consumes: `RegionSpec` from Task A1 (`from dcist_sim_isaac.scenario import RegionSpec`).
- Produces: `augment_dsg_with_regions(G, regions: list[RegionSpec]) -> dict` where `G` is a `spark_dsg.DynamicSceneGraph`, mutated in place; returns summary `{region_id: {"symbol": "R(n)", "n_places": int}}`. Raises `ValueError` if a region captures zero MESH_PLACES nodes. Imports spark_dsg only (NO Isaac, NO ROS, NO neo4j) — unit-testable in the workspace python.

Behavior:
1. For each region: allocate the next free ROOMS-layer symbol (`spark_dsg.NodeSymbol('R', index)` with index = max existing Room index + 1, or 0), create the node with `spark_dsg.RoomNodeAttributes()` (set `position = [x, y, ~mean place z]`, `name = region.label`, `semantic_label = <labelspace id>`), add it to `spark_dsg.DsgLayers.ROOMS`.
2. Membership: every `MESH_PLACES` node with `hypot(px - x, py - y) <= radius` gets `G.insert_edge(room_id, place_id)` (spark_dsg records parent-child across layers; verify with the API — the heracles ingest reads Room→place containment from DSG parent edges).
3. Labelspace: read metadata `labelspaces["_l4p0"]`; if absent create it; if `label` not present append `[next_int_id, label]`; write back via `G.metadata.add({...})` or `set_labelspace` (check the spark_dsg pin's actual API — labelspace API skew is a known trap, see memory `project-hydra-labelspace-mesh-crash`); set the room node's `semantic_label` to that id.
4. Re-running on a graph that already has a room with `name == label` updates that room (position, edges) instead of adding a duplicate.

from dcist_sim_isaac.region_injector import augment_dsg_with_regions
from dcist_sim_isaac.scenario import RegionSpec

def _graph_with_places(centers):
    G = spark_dsg.DynamicSceneGraph()
    for i, (x, y) in enumerate(centers):
        attrs = spark_dsg.Place2dNodeAttributes()  # MESH_PLACES node type; verify class name
        attrs.position = [x, y, 0.0]
        G.add_node(spark_dsg.DsgLayers.MESH_PLACES, spark_dsg.NodeSymbol('P', i).value, attrs)
    return G

def test_injects_room_with_member_places():
    G = _graph_with_places([(0, 0), (1, 1), (10, 10)])
    out = augment_dsg_with_regions(
        G, [RegionSpec("intersection", "intersection", 0.5, 0.5, 3.0)])
    assert out["intersection"]["n_places"] == 2
    rooms = list(G.get_layer(spark_dsg.DsgLayers.ROOMS).nodes)
    assert len(rooms) == 1

def test_zero_member_places_raises():
    G = _graph_with_places([(10, 10)])

    augment_dsg_with_regions(G, spec)
    assert len(list(G.get_layer(spark_dsg.DsgLayers.ROOMS).nodes)) == 1
