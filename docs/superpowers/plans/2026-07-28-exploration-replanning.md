# Exploration + Replanning in Isaac Sim (3 MIT floors) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Put the 3-floor MIT labeled-object catalogs into Isaac Sim scan environments and add an explore→ground→replan loop so PDDL tasks referencing not-yet-observed objects force real exploration, ending in a verified e2e mission (objectnav gate + pick-place-into-region gate) with metrics for the paper.

**Architecture:** Harness-level exploration loop (`explore_mission.py`, modeled on `camp_mission_smoke.py`'s phase structure) drives a robot with live GT-semantics perception (hydra builds the OBJECTS layer as the camera sees proxy objects). A pure-python exploration policy picks waypoints over the env's `.floor.npz` traversable grid with a visited-disk mask (robot "knows the floor plan but not object locations"). A contained omniplanner seam adds typed grounding/solver errors (MissingSymbolError, PddlUnsolvableError) so "object absent" is distinguishable from "goal unreachable" — used in-process by the harness and preserved in the node. Once the target class appears in the live DSG, the proven camp pipeline finishes the mission: SaveDsg → ingest to Neo4j (region injection) → planning session (heracles→omniplanner) → PddlGoalMsg → executor → strict tied verification.

**Tech Stack:** Isaac Sim 6.0 (kinematic tier + magic grasp), hydra + hydra_ros, omniplanner/dsg_pddl + Fast Downward, heracles/Neo4j, spark_dsg, numpy/scipy/skimage (pure-python policy), pytest.

# grounding_errors.py
from dataclasses import dataclass, field

@dataclass
class MissingSymbol:
    name: str            # e.g. "o123" as it appeared in the goal
    kind_hint: str = ""  # "object" | "region" | "place" | "" when unknown

class GroundingError(Exception): ...

class MissingSymbolError(GroundingError):
    def __init__(self, missing: list[MissingSymbol], goal: str):
        self.missing = missing
        self.goal = goal
        super().__init__(f"goal references symbols absent from the scene graph: {[m.name for m in missing]}")

class PddlSolverError(Exception):
    def __init__(self, message: str, returncode: int | None = None):
        self.returncode = returncode
        super().__init__(message)

class PddlUnsolvableError(PddlSolverError): ...   # FD rc 10/11/12
class PddlTimeoutError(PddlSolverError): ...      # FD rc 21/23/24 (no plan file)
class PddlMalformedError(PddlSolverError): ...    # FD rc 31
```

    def mark_visited(self, x: float, y: float, radius_m: float) -> None: ...
    def coverage(self) -> float: ...              # visited∩traversable / traversable
    def frontier_count(self) -> int: ...
    def next_waypoint(self, x: float, y: float, min_step_m: float = 2.0,
                      window_m: float = 6.0) -> tuple[float, float, float] | None: ...
        # (wx, wy, yaw) toward highest-gain reachable unvisited area; BFS over
        # traversable cells (walls respected); None when no unvisited cell reachable.
    def path_is_traversable(self, x0,y0,x1,y1) -> bool: ...   # straight-line cell check
```
Semantics: traversable = floor-observed AND wall-clearance ≥ inflation, computed exactly like `check_scenario_placement._traversable_grid` (wall-grid resolution, floor resampled by world-centre lookup — grids have different origins; COPY that logic, do not kron/zoom). Visited starts all-False. `next_waypoint`: BFS from the robot cell over traversable cells; first BFS ring whose cell has ≥ K unvisited traversable cells within `window_m` wins; waypoint = that cell's world centre, yaw pointing at the local unvisited centroid; cells closer than `min_step_m` (BFS distance) are skipped so the robot keeps moving. Deterministic (ties broken by (iy,ix) order). Pure numpy + collections.deque; scipy allowed only for the distance transform (already a check_scenario_placement dep).

```python
grid = ExplorationGrid.from_floor_npz(scenario_env_npz, inflation_m=scenario.nav.inflation_radius_m)
while True:
    grid.mark_visited(*node.odom_xy(), radius_m=args.sensor_radius)
    found = node.objects_of_class(args.target_class)
    log_event("ground_attempt", found=len(found), coverage=grid.coverage())
    if found: break
    if grid.coverage() >= args.coverage_limit or elapsed > args.explore_budget_s:
        log_event("abort", reason="explored_out"); return EXIT_NOT_FOUND (4)
    wp = grid.next_waypoint(*node.odom_xy())

    node.send_follow(wp, plan_id); log_event("waypoint_sent", wp=wp)
    wait arrival (arrival_tol, waypoint_timeout) polling odom;
      mark_visited every 0.5 s along the way; timeout -> log + continue (pick a new wp)
```

6. Teardown (stop-file, tmux kill both sockets), write summary.json, `os._exit(code)`. Exit codes: 0 both gates pass (or gate 1 when no `--region`), 4 not found/explored out, 5 unsolvable, 2 infra failure.
